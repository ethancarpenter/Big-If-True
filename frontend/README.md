# Big If True frontend

The Next.js App Router frontend for Big If True, a tabletop RPG campaign manager. Built with React, TypeScript, Tailwind CSS, and React Flow.

See the [root README](../README.md) for prerequisites, environment configuration, database and API startup, and development accounts.

After completing that setup, run these commands from `frontend/`:

```bash
npm ci
npm run dev
```

Validation and production build:

```bash
npm run lint
npm run build
```

See [deployment requirements](../docs/DEPLOYMENT.md) before hosting the application.
